# معدل DZ — حاسبة المعدلات والاستدراك في الجزائر (2026/2027)

تطبيق ويب عصري ومتكامل لحساب المعدلات المدرسية (الابتدائي، المتوسط، الثانوي) والمعدل الجامعي LMD، مع ميزة رائدة لمحاكاة امتحانات الاستدراك وحساب العلامة المطلوبة للنجاح.

## محتويات الحزمة
- `public/robots.txt`: ملف توجيه عناكب محركات البحث.
- `public/sitemap.xml`: خريطة الموقع الكاملة الجاهزة للأرشفة في Google Search Console.
- `public/_redirects`: ملف إعادة التوجيه لـ Cloudflare Pages و Netlify لحل مشكلة 404.
- `public/.htaccess`: ملف إعادة التوجيه لخوادم Apache و Hostinger.
- `vercel.json`: ملف التوجيه الخاص بـ Vercel.

## خطوات التشغيل محلياً
1. تثبيت الحزم:
   ```bash
   npm install lucide-react
   ```
2. بناء المشروع للإنتاج:
   ```bash
   npm run build
   ```
3. سيتم إنشاء مجلد `dist` يحتوي على ملفات الموقع الجاهزة للنشر المباشر.
